# Marca ASHA

Logo diseñado por Adys. El kit completo (`.ai`, PDF, PNG en varias versiones y la Ficha Gráfica, que es un primer intento de guía) está en el Drive de Ernesto, no en este repo.

- `asha-logo.svg`: logo completo (corona, ASHA, JEWELRY). Extraído en vector del PDF del kit, versión "positivo".
- `asha-solo-letras.svg`: ASHA y JEWELRY sin la corona, del mismo PDF.

`herramientas/adornos.py` los lee para la web: el diamante y la estrella son subtrazados del propio logo, no dibujos aparte. `herramientas/marca.py` genera desde aquí los iconos y la imagen para redes.

Datos de la Ficha Gráfica:

| | Hex | RGB | CMYK |
|---|---|---|---|
| Oro | `#D5A332` | 213 163 50 | 18 36 100 0 |
| Oro claro | `#FDCF55` | 253 207 85 | 0 18 82 0 |
| Negro | `#000000` | 0 0 0 | 0 0 0 100 |
| Aqua de fondo | `#CEF2F5` | 206 242 245 | 10 0 7 0 |

Tipografías del logo: Jitter ("ASHA") y Raleway ("JEWELRY"). En el logo están convertidas a trazos. Ojo: el PDF de la ficha usa **JitterDEMO**, la versión de demostración, que normalmente no permite uso comercial. Conviene confirmar con Adys la licencia de Jitter.
